# С нуля до магната — Empire Edition

Мобильный бизнес-симулятор на HTML/CSS/JavaScript, который можно опубликовать на GitHub Pages и подключить к Telegram Mini App.

## Запуск
Откройте `index.html` в браузере. Для публикации загрузите `index.html`, `style.css`, `game.js`, `README.md` в корень публичного GitHub-репозитория и включите GitHub Pages (`Settings → Pages → Deploy from a branch → main → /root`).

## Игровые системы
- 12 компаний с растущей стоимостью, уровнями и пассивным доходом
- 6 постоянных улучшений
- 5 исследований за очки науки
- 4 типа сотрудников
- 5 районов города с бонусами
- уровни, опыт, репутация и ранги
- задания, достижения и ежедневные награды со streak
- рекламные кампании и случайные события
- престиж / новая карьера с постоянным бонусом
- журнал событий, статистика, локальное сохранение, экспорт резервной копии
- офлайн-доход до 8 часов
- адаптивный интерфейс для мобильных устройств и Telegram WebApp SDK

## Важно
Это полноценный **играбельный браузерный прототип**, но не серверная многопользовательская игра. Сохранение находится в localStorage на конкретном устройстве. Для аккаунтов, синхронизации, лидербордов, рефералов, покупок за реальные деньги и защиты экономики нужен backend. Никогда не помещайте токен BotFather в frontend-код.
